# 도면 증강 4D 뷰어 (시험판)

인쇄한 도면의 ArUco 마커를 태블릿 카메라로 비추면, 도면 축척에 맞춰 3D 모델이 올라오고 날짜에 따라 공정이 진행되는 웹 뷰어입니다. 설치 없이 브라우저에서 동작합니다.

**이 저장소의 모델과 도면은 시험용 가상 자료입니다.** 실제 과업 자료는 넣지 않습니다.

## 써 보기

1. `drawing.html`을 열어 A4 가로, **배율 100%**로 인쇄합니다. 인쇄 후 100mm 눈금을 자로 확인합니다.
2. 태블릿으로 도면의 QR을 찍거나 `index.html`을 엽니다. 카메라 권한을 허용합니다.
3. 마커가 화면에 들어오게 도면을 비춥니다. 아래 막대로 날짜를 옮기거나 재생합니다.

카메라 없이 확인하려면 `index.html?demo` 를 엽니다(시험 사진 사용).

## 자료 꾸러미 (`data/`)

| 파일 | 내용 |
|---|---|
| `model.glb` | 형상. 객체 하나가 작업 하나이고 객체 이름이 작업 ID |
| `tasks.csv` | task_id, name, start, end, type(시공·가설·철거) |
| `drawings.csv` | 도면 번호, 마커 번호, 축척, 마커 한 변(mm), 마커 중심에서 모델 원점까지 거리(mm), 회전, 모델 파일 |
| `info.json` | 원본, 내보낸 날짜 |

뷰어에는 작업 이름이나 날짜가 들어 있지 않습니다. `data/` 폴더만 바꾸면 다른 모델·공정으로 바뀝니다.

## 구성

- 마커 인식: js-aruco2 (ARUCO_MIP_36h12), 자세는 마커 네 꼭짓점으로 계산
- 3D: three.js, glTF
- 오프라인: 한 번 열면 파일을 기기에 저장해 두고, 통신이 없을 때 저장본을 씁니다 (`sw.js`)
- 주소 옵션: `?fov=62` 카메라 가로 화각(도) 보정, `?day=2028-06-15` 시작 날짜

## 알려진 한계

- 마커가 화면에 보이는 동안만 증강됩니다.
- 카메라 화각을 기기에서 읽지 못해 62°로 가정합니다. 기기에 따라 높이 방향이 조금 어긋날 수 있어 `?fov=`로 보정합니다.
- 카메라는 https 주소에서만 켜집니다.

`vendor/`의 라이브러리는 각자의 라이선스를 따릅니다(three.js MIT, js-aruco2 MIT, qrcode-generator MIT).
